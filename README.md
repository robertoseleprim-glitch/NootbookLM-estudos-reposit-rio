# NootbookLM-estudos-reposit-rio
Uma imersão no gênero Lo-Fi Hip Hop para compreender suas qualidades musicais, trajetória e grande apelo com o público. O projeto aborda a forte ligação do estilo com animes e gifs 3D, além de investigar o uso de Inteligência Artificial na criação e monetização de canais dedicados a essa estética sonora contemporânea.
